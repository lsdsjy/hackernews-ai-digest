# **Gleam’s OTP Library: Type-Safe, Fault-Tolerant Actors on the BEAM**  

Gleam's OTP library brings the power of Erlang's **actor model** to Gleam, enabling developers to build **fault-tolerant, multicore** applications with strong **type safety**. Built on the BEAM (the Erlang virtual machine), this library provides a familiar yet modern approach to concurrency and error handling.  

## **Why Use Gleam OTP?**  
✅ **Type-safe actors & messages** – No more runtime errors from mismatched message patterns!  
✅ **Fully compatible with Erlang OTP** – Integrates seamlessly with existing BEAM ecosystems.  
✅ **Supervision trees for self-healing** – If something crashes, supervisors restart it automatically.  
✅ **Performance on par with Erlang** – Optimized for the BEAM’s lightweight concurrency model.  

### **Example: A Simple Stateful Actor**  
```gleam  
import gleam/erlang/process.{type Subject}  
import gleam/otp/actor  

pub fn main() {  
  let assert Ok(actor) = actor.new(0)  
    |> actor.on_message(handle_message)  
    |> actor.start  

  // Send messages (asynchronous and synchronous)  
  actor.send(actor.data, Add(5))  
  actor.send(actor.data, Add(3))  
  assert actor.call(actor.data, waiting: 10, sending: Get) == 8  // Waits for a reply  
}  

pub fn handle_message(state: Int, message: Message) -> actor.Next(Int, Message) {  
  case message {  
    Add(i) -> actor.continue(state + i)  // Update state  
    Get(reply) -> {  
      actor.send(reply, state)  // Reply with current state  
      actor.continue(state)  
    }  
  }  
}  

pub type Message {  
  Add(Int)  
  Get(Subject(Int))  
}  
```  

## **Key Abstractions**  
🔹 **Process** – The foundational building block (lowest level).  
🔹 **Actor** – The most common actor type (similar to Erlang’s `gen_server`).  
🔹 **Supervisor** – Automatically restarts child processes on failure:  
   - **Static supervisor** (fixed set of children)  
   - **Factory supervisor** (dynamic child processes)  

### **Known Limitations**  
- Some OTP debugging messages are **not yet supported** (they’re silently discarded).  
- More supervision strategies are still in development.
