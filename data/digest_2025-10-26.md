### **Are We Fast Yet? Benchmark Suite Expands to More Languages**  

**TL;DR:** The *Are-we-fast-yet* benchmark suite—originally designed to compare the performance of dynamic language implementations—has been extended with implementations in **Oberon, C++, C, Pascal, Micron, and Luon**. The repository, maintained by Rochus Keller, aims to broaden the scope of performance comparisons across diverse programming languages.  

#### 🔍 **What’s Inside?**  
- **Multiple Implementations** in low-level and high-level languages:  
  - **C (29%), C++ (24%)** for baseline performance  
  - **Lua (17%), Luau (17%)** for dynamic language comparisons  
  - **Modula-2 (Oberon), Pascal (5%), and Micron/Luon** (an experimental language?)  
- **Original Benchmark Suite** focuses on dynamic dispatch performance (JavaScript, Python, Ruby, etc.).  

#### 🚀 **Why It Matters**  
- Helps compare **optimization techniques** across different language families.  
- For language designers: **How fast can a VM or interpreter be?**  
- For performance enthusiasts: How do **compiled languages (C, Pascal, Oberon) compare to dynamic counterparts?**  

#### 📂 **Getting Started**  
- Check the [main repo](https://github.com/smarr/are-we-fast-yet) for original benchmarks.  
- Each language version has its own subdirectory (e.g., `Cpp`, `Oberon`) with build instructions.
