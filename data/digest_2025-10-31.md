# **Tracing Performance Issues with Perfetto: A Swiss Army Knife for Linux**  

A recent talk at the **2025 Tracing Summit** showcased **Perfetto**—an incredibly versatile tool for debugging performance issues on Linux, far beyond its original use cases in Android and Chrome. Here’s what you need to know.  

---

## **What is Perfetto?**  
Perfetto is a **suite of tools** designed for collecting, analyzing, and visualizing performance data. Unlike single-purpose profilers, Perfetto is **flexible**, supporting:  
- **Data capture** (via an SDK, daemons, and kernel interfaces).  
- **Fast trace storage** (using an efficient protobuf format).  
- **Powerful analysis** (via SQL queries in its web UI or a Python API).  

**Key features:**  
✔ **Multi-format support** (perf.data, ftrace, Chrome JSON).  
✔ **Local-first analysis**—everything happens in the browser, no cloud uploads required.  
✔ **Self-hosting**—you can run the UI yourself if needed.  

---

## **A Real-World Example: Debugging a GPU + CPU Rendering Issue**  
A demo Rust program **generates and renders a fracta**l (Julia set) at **60 FPS**, but **periodically suffers severe frame drops**. Perfetto helps uncover why.  

### **Step 1: Traditional Approach with `perf`**  
First, the speaker tried `perf record` to generate a **flamegraph**:  
```sh
perf record -k mono -g ./fractal_renderer  
perf script | stack-collapse-perf.pl --all | flamegraph.pl > flamegraph.svg  
```
What it showed:  
🔥 Worker threads were mostly doing `sin` and `cos` calculations—nothing unusual.  

**Limitation:**  
- Flamegraphs **aggregate** time, hiding **temporary stalls or synchronization issues**.  

### **Step 2: Switching to Perfetto for a More Detailed View**  
Perfetto provides a **timeline-based** view, exposing:  
✅ **Thread scheduling** (when threads run and when they’re blocked).  
✅ **GPU activity**.  
✅ **Lock contention and synchronization issues**.  

**Finding the real culprit**:  
- A deeper dive revealed **GPU command buffer stalls**—something a flamegraph couldn’t easily show.  
- Perfetto’s SQL interface allowed querying specific events, linking CPU and GPU workloads dynamically.
