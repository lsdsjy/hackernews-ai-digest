### URLs are state containers

#### [Submission URL](https://alfy.blog/2025/10/31/your-url-is-your-state.html) | 473 points | by [thm](https://news.ycombinator.com/user?id=thm) | [205 comments](https://news.ycombinator.com/item?id=45789474)

# The Hidden Power of URLs: Your Address Bar as a State Management Tool  

### **A Personal "Aha" Moment with PrismJS**  

The author recently had an epiphany while working on **SQL syntax highlighting** for a blog post. Overwhelmed by PrismJS’s configuration options, they stumbled upon a **comment in their code** containing a URL that perfectly reconstructed their previous setup:  

> **`https://prismjs.com/download.html#themes=prism&languages=markup+css+clike+javascript+bash+css-extras+markdown+scss+sql&plugins=line-highlight+line-numbers+autolinker`**  

That URL wasn't just a link—it was **a complete state snapshot**. Every checkbox, dropdown, and setting was preserved. No cookies, no databases, no `localStorage`—just raw information in the URL itself.  

### **Why Aren’t We Using URLs for State Management More?**  

Most frontend engineers reach for complex state managers (**Redux, Context, Zustand, etc.**), often overlooking one of the **web’s oldest and most powerful tools: the URL.**  

**URLs give us for free:**  
✅ **Shareability** – Send someone a link, and they see exactly what you see.  
✅ **Bookmarkability** – Save your current view effortlessly.  
✅ **Browser history** – The back button works magically.  
✅ **Deep linking** – Jump straight to a specific app state.  

### **Dissecting the URL as a State Container**  

A URL isn’t just an address—it’s **a structured way to encode state**, with different parts serving different purposes:  

🔹 **Path Segments (`/users/123/posts`)**  
→ **Best for hierarchy** (e.g., site structure, resource navigation).  

🔹 **Query Parameters (`?page=2&limit=20`)**  
→ **Ideal for filtering, options, and configs** (e.g., search queries, UI settings).  

🔹 **Anchor Fragment (`#features` or `#L20-L35`)**  
→ **Great for in-page navigation** (or even **line highlights**, like on GitHub).  

### **Popular Patterns for Parameter Encoding**  

📌 **Multiple Values** – Delimit with `+` or `,`  
   → `?languages=js+python+rust`  

📌 **Boolean Flags** – Use presence-as-truthy  
   → `?darkMode` (no value = true)  

📌 **Nested Data** – JSON, base64, or key-value pairs  
   → `?filters=category:tech,status:active`  

📌 **Bracket Notation** (for arrays—though quirky)  
   → `?tags[]=react&tags[]=frontend`  

### **Real-World Examples**  

- **GitHub** (`#L20-L30`) → **Line selection**  
- **PrismJS** (`?languages=js&theme=dark`) → Complete config  
- **Google Docs** (`/edit#heading=h.abc123`) → Scroll to a heading  

### **Final Takeaway**  

Instead of treating the URL as an **afterthought**, frontend devs should **design it intentionally**—leveraging its power for **state persistence, sharing, and navigation**.  

🔗 **URLs are more than UI. They’re free, durable state containers.**  

Would love to hear your favorite examples of **clever URL use** in the wild! 🚀

### Notes by djb on using Fil-C

#### [Submission URL](https://cr.yp.to/2025/fil-c.html) | 347 points | by [transpute](https://news.ycombinator.com/user?id=transpute) | [229 comments](https://news.ycombinator.com/item?id=45788040)

### **djb Explores Fil-C: A Promising Memory-Safe C/C++ Compiler**  

**Key Highlights:**  
- **Fil-C shows impressive compatibility** with existing libraries and applications, often working without modifications.  
- **Performance impact:** Microbenchmarks indicate Fil-C-compiled code runs **1x–4x slower** than Clang, depending on the workload.  
- **Memory usage concerns:** Compilation can be greedy—djb had to **expand swap space to 36GB** to avoid crashes on a 12GB RAM system.  

---  

#### **Getting Started with Fil-C**  
djb has been rigorously testing the **Fil-C compiler (filcc, fil++)**, a memory-safe variant of C/C++, aiming to secure his machines with minimal changes.  

- **Installation options:**  
  - Source-based (preferred) via `filian-install-compiler` (~86 minutes on a Zen 4 system).  
  - Prebuilt binaries or via **Filnix** (Mikael Brockman’s Nix-based distribution).  
  - **Debian 13** is recommended due to newer toolchain dependencies.  

- **Recommended tools for setup:**  
  ```bash  
  apt install autoconf-dickey build-essential bison clang cmake flex gawk gettext ninja-build patchelf quilt ruby texinfo time  
  ```  

---  

#### **Performance & Practical Use**  
- **Crypto benchmarks:** ~9000 tests show Fil-C trailing Clang by **a factor of 1–4x** (Zen 4, single-core).  
- **Compatibility quirks:**  
  - **Musl vs. Glibc:** Fil-C defaults to **glibc** since musl breaks some included packages (e.g., `attr`, `elfutils`).  
  - **Util-linux issue:** The `taskset` utility fails due to syscall usage—needs patching or alternative affinity management.  

---  

#### **Automated Builds with `build-parallel.py`**  
djb replaced the slow, serial `build_all_slow.sh` with a **parallelized Python script** (`build-parallel-20251023.py`), achieving:  
- **61 targets** built in **~101 minutes** (vs. much longer sequentially).  
- **Only one failure (`libcap`)** due to linker issues.  

---  

#### **Takeaways for Early Adopters**  
✅ **Works surprisingly well** for unmodified code.  
⚠️ **Memory-hungry builds**—consider beefy systems (512GB RAM) or ample swap.  
🔧 **Minor patches needed** for some tools (e.g., `taskset`, `libcap`).  

**Next steps:** djb aims to expand adoption across managed systems while refining tooling. **Could Fil-C be the future of safer C?**

# **Hacker News Daily Digest: Mock API Magic with Shell Scripting**

Today's standout story showcases **mock**, a versatile tool for building and testing APIs with the simplicity of shell scripting. Here's what caught our attention:

### 🔥 **Key Highlights**
- **Delayed Endpoints** - Want to simulate slow API responses? Mock lets you add delays (e.g., 2 seconds) to specific endpoints using middleware logic.
- **Polyglot API** - Serve endpoints powered by **Node.js, Python, and PHP** all in one API server. A curl to `/js`, `/python`, or `/php` returns greetings from each runtime.
- **Stateful Server** - Track request counts in a temporary file to create an API that remembers how many times it’s been called.
- **Full CRUD API** - A surprisingly elegant demo using `jq` and shell scripts to create, read, and list users in JSON—complete with error handling.

### **Why This Matters**
- **No Framework Needed**: Skip Flask, Express, or Django—use shell commands and environment variables.
- **Rapid Prototyping**: Perfect for quick API mocking, testing edge cases, or even makeshift microservices.
- **Unix Philosophy**: Leverages CLI tools (`jq`, `bc`, `sponge`) to keep logic simple yet powerful.
